# 语你合唱

语你合唱是一款英语与日语歌曲陪练原型：听懂喜欢的歌，跟着伙伴练会一句外语。

## 开发

```bash
npm install
npm run dev
```

`npm run dev` 只启动 Vite 页面，不运行 Netlify 函数；要在本机联调日语自动释义，请使用 Netlify CLI 的 `netlify dev` 并在仅本机可见的服务端环境配置密钥。不要将密钥写进前端或提交到 Git。

应用包含一首原创英文短歌《Take a Breath》（四句、20.88 秒），不需要 API Key。支持 Speech Recognition 的浏览器会在获得麦克风权限后识别英文跟读，并对识别文字进行词序列动态规划比对。浏览器的识别服务可能在云端处理音频；应用本身不保存录音。缺少识别能力、权限或设备时会显示原因，并提供明确标注的模拟反馈示例；示例不作为识别结果或学习成绩。

导入日语歌曲时可选择“日本語”，使用 `ja-JP` 浏览器识别和日语文字对齐。浏览器日语音色可用于“听示范朗读”，它不是歌曲原唱。假名写法会先归一后比较；汉字与假名可能同音时只提示文字写法待确认。日语词语讲解和中文释义可点击按钮逐句自动生成，结果来自服务端模型，**需要人工核对**，不代表专业翻译。每次最多处理 20 句，再次点击可继续；已生成内容保存在本机 IndexedDB，切换歌曲不会混用。

跟读时的临时识别文字只显示“识别中”；收到浏览器标记为最终结果的文字后，才显示逐词反馈并增加真实跟读次数。点击“结束跟读”会请求识别服务返回最终结果；安静无语音、权限拒绝及服务失败均不计数。

每句旁可听原唱片段或开始跟读；点击重点词可优先听词典发音，失败时尝试浏览器 en-US 合成朗读。真实跟读的次数、最近识别文字、逐词差异、最近三次比对结果与建议保存在当前浏览器的 `localStorage`；导入歌曲的音频与解析后的歌词保存在此设备的 IndexedDB。刷新后可恢复本地歌曲，但清除浏览器站点数据后会失去这些文件和记录。音频文件不会上传服务器，本地歌曲与练习记录不会跨设备同步。文字比对不能判断音准或具体发音。

比对先按英文单词切分，并归一大小写、常见标点和缩写；再用编辑距离动态规划对齐标准歌词与浏览器识别文字。页面按原歌词顺序标出匹配、疑似漏读和疑似替换，单独列出疑似多出的词。对 `n` 个标准词、`m` 个识别词，时间与空间复杂度均为 `O(nm)`。学习进度页基于每句最近三次真实跟读结果与距上次练习的天数，确定性地推荐下一句；模拟反馈、播放和点击歌词不参与统计。该推荐只表示文字比对后的复习顺序，不是发音评分。

“学习进度 → 我的歌曲”可以重新打开已导入的歌曲，也可以删除该歌曲的音频、歌词和对应练习记录。浏览器存储空间不足、站点存储被禁用或音频文件损坏时，页面会提示原因；浏览器清除站点数据后，“我的歌曲”会显示空状态。

“学习进度 → 生成我的学习报告”只分析当前歌曲在此浏览器中的真实跟读记录。报告统计每句最近最多三次详细反馈，展示反复出现的标准词差异、疑似多出词、复习依据和趋势；旧记录若只有最近一次反馈，趋势会显示样本不足。报告不会上传音频、歌词或转写文字。点击“打印 / 保存为 PDF”会打开浏览器打印界面，由浏览器提供另存为 PDF 选项，网页本身不生成 PDF 文件。

## 公共 HTTPS 演示（Netlify）

本项目由 Netlify 构建 Vite 页面及 `netlify/functions/japanese-study.mjs` 服务端函数。Netlify 连接 GitHub 仓库 `cantaloupeham/yuni-chorus` 的 `work` 分支，运行 `npm run build` 并发布 `dist/`。体验网址为 https://yuni-chorus.netlify.app/。英语演示与日语跟读无需 API Key；**日语自动释义需要在 Netlify 的环境变量中配置 `OPENAI_API_KEY`（Functions 可用），并重新部署**。密钥不得使用 `VITE_` 前缀。建议为公开演示使用单独的受限项目密钥并设置消费上限。

若更名后 Netlify 的仓库连接未自动跟随，请在站点配置中重新连接 `cantaloupeham/yuni-chorus`，保持生产分支 `work`、构建命令 `npm run build`、发布目录 `dist`。

演示版音频为用户提供的原创歌曲；“导入我的歌曲”可以选择本地 MP3、WAV 或 M4A 和对应 LRC 文件，在浏览器内播放和同步歌词，**音频文件不会上传**。用户点击日语自动释义后，浏览器仅把待处理的单句歌词发给本站 Netlify 函数，函数再将该句发送给模型服务；不发送音频、整首歌词或语音识别文本。未配置密钥、服务出错时显示明确提示，不生成占位翻译。请勿将商业歌曲或 API Key 提交到仓库。

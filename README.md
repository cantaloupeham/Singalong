# 语你合唱

语你合唱是一款英语歌曲陪练原型：听懂喜欢的歌，跟着伙伴练会一句外语。

## 开发

```bash
npm install
npm run dev
```

应用包含一首原创英文短歌《Take a Breath》（四句、20.88 秒），不需要 API Key。支持 Speech Recognition 的浏览器会在获得麦克风权限后识别英文跟读，并对识别文字进行词序列动态规划比对。浏览器的识别服务可能在云端处理音频；应用本身不保存录音。缺少识别能力、权限或设备时会显示原因，并提供明确标注的模拟反馈示例；示例不作为识别结果或学习成绩。

跟读时的临时识别文字只显示“识别中”；收到浏览器标记为最终结果的文字后，才显示逐词反馈并增加真实跟读次数。点击“结束跟读”会请求识别服务返回最终结果；安静无语音、权限拒绝及服务失败均不计数。

每句旁可听原唱片段或开始跟读；点击重点词可优先听词典发音，失败时尝试浏览器 en-US 合成朗读。真实跟读的次数、最近识别文字、逐词差异、最近三次比对结果与建议保存在当前浏览器的 `localStorage`；导入歌曲的音频与解析后的歌词保存在此设备的 IndexedDB。刷新后可恢复本地歌曲，但清除浏览器站点数据后会失去这些文件和记录。歌曲不会上传服务器，也不会跨设备同步。文字比对不能判断音准或具体发音。

比对先按英文单词切分，并归一大小写、常见标点和缩写；再用编辑距离动态规划对齐标准歌词与浏览器识别文字。页面按原歌词顺序标出匹配、疑似漏读和疑似替换，单独列出疑似多出的词。对 `n` 个标准词、`m` 个识别词，时间与空间复杂度均为 `O(nm)`。学习进度页基于每句最近三次真实跟读结果与距上次练习的天数，确定性地推荐下一句；模拟反馈、播放和点击歌词不参与统计。该推荐只表示文字比对后的复习顺序，不是发音评分。

“学习进度 → 我的歌曲”可以重新打开已导入的歌曲，也可以删除该歌曲的音频、歌词和对应练习记录。浏览器存储空间不足、站点存储被禁用或音频文件损坏时，页面会提示原因；浏览器清除站点数据后，“我的歌曲”会显示空状态。

“学习进度 → 生成我的学习报告”只分析当前歌曲在此浏览器中的真实跟读记录。报告统计每句最近最多三次详细反馈，展示反复出现的标准词差异、疑似多出词、复习依据和趋势；旧记录若只有最近一次反馈，趋势会显示样本不足。报告不会上传音频、歌词或转写文字。点击“打印 / 保存为 PDF”会打开浏览器打印界面，由浏览器提供另存为 PDF 选项，网页本身不生成 PDF 文件。

## 公共 HTTPS 演示（Vercel）

本项目是 Vite 单页应用。Vercel 使用仓库中的 `vercel.json` 执行 `npm run build`，发布 `dist/`。选择 GitHub 仓库 `cantaloupeham/Singalong`，将 Production Branch 设为 `work`，即可让后续提交自动部署。无需配置 API Key。

在 Vercel 控制台：Add New → Project → Import Git Repository → 选择 `cantaloupeham/Singalong` → Framework Preset 选 Vite → Root Directory 保持 `./` → Build Command `npm run build` → Output Directory `dist` → Deploy。部署完成后到 Project Settings → Environments / Git，把 Production Branch 设为 `work`；若首次部署来自 `main`，切换后从 `work` 分支重新触发一次生产部署。

演示版音频为用户提供的原创歌曲；“导入我的歌曲”可以选择本地 MP3、WAV 或 M4A 和对应 LRC 文件，在浏览器内播放和同步歌词，文件不会上传。请勿将商业歌曲或任何 API Key 提交到仓库。未来需要 AI 接口时，应使用 Vercel 服务端函数和服务端环境变量，避免把密钥放进 `VITE_` 变量。
